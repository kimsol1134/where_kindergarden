## 해결된 과거 이슈

- 시도·시군구 코드를 2026년 유치원알리미 공식 코드표로 재생성했다.
- 광주·전남 통합, 강원·전북 특별자치도, 인천·화성 행정구역 개편을 현재 코드로 정규화했다.
- 50㎡를 넘는 1인당 교실 면적 이상치는 0으로 정규화한다.
- 과거 실외놀이터 면적에 조리실 면적을 넣던 오매핑을 제거했다. 2026 공개 원본에 해당 필드가 없어 `outdoor_playground_area`는 0이며 메타데이터에 명시한다.
- 좌표가 비어 있는 기관은 공식 상세 페이지, 이전 동일 기관 좌표, Kakao 주소 검색 순으로 보완하며 출처별 개수를 `kindergartens.meta.json`에 기록한다.

## 자동 차단 조건

`scripts/validate-public-data.ts`는 다음 상태를 게시 전에 실패로 처리한다.

- 유치원 ID 중복, 체크섬 불일치, 좌표·지역 코드 오류
- 공식 구성 데이터 또는 식별자 조인 커버리지 하락
- 후기의 비현행 기관 참조, 내부 기관 ID 불일치, 통합/시도/시군구 샤드 불일치
- 결원 지역 누락, 상세 커버리지 98% 미만, 현행 카탈로그 매칭 95% 미만
- 카탈로그·지역 코드·후기 재결합 14일, 결원 72시간 최신성 SLA 초과

후기 콘텐츠 발견 주기는 별도 30일 목표로 표시한다. 관련성 삭제는 자동 게시하지 않고 사람 승인 절차를 유지한다.
