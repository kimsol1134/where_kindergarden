# Claude in Chrome - 유치원 후기 수집 가이드

> 이 프롬프트는 Claude in Chrome 확장 프로그램을 사용하여 유치원 후기를 반자동으로 수집하기 위한 가이드입니다.

---

## 개요

API로 접근할 수 없는 후기(폐쇄 카페, 동적 콘텐츠 등)를 Claude in Chrome을 통해 수집합니다.

### 수집 대상 소스
| 소스 | URL | 특징 |
|------|-----|------|
| 네이버 블로그 | search.naver.com → 블로그 탭 | 가장 많은 후기 |
| 네이버 카페 | search.naver.com → 카페 탭 | 맘카페 후기 다수 |
| 다음 카페 | search.daum.net → 카페 탭 | 지역 맘카페 |
| 맘스홀릭베이비 | www.momsholic.com | 육아 커뮤니티 |

---

## 수집 워크플로우

### Step 1: 검색 실행

1. 브라우저에서 네이버 검색 페이지 열기
2. 검색어 입력: `[유치원명] [지역] 후기`
   - 예: `"예은유치원" 강남구 후기`
   - 예: `"중앙유치원" 수원 후기`
3. **블로그** 또는 **카페** 탭 선택

### Step 2: 결과 분석

각 검색 결과에 대해:

1. **제목 확인**: 유치원 관련 후기인지 판별
2. **스니펫 확인**: 실제 경험 후기인지 확인
3. **URL 기록**: 관련성 높은 링크 수집

### Step 3: 필터링 규칙

#### 포함 기준 (수집 대상)
- 유치원명이 제목이나 본문에 포함
- "후기", "다녀보니", "재원생", "솔직후기" 등 키워드 포함
- 실제 학부모 경험담으로 보이는 글

#### 제외 기준 (스팸)
다음 키워드가 포함된 글은 제외:

| 카테고리 | 제외 키워드 |
|----------|-------------|
| 학원 (유치원 아님) | 태권도, 피아노학원, 음악학원, 축구클럽, 수영장 |
| 부동산 | 임장, 분양, 모델하우스, 재건축, 전세, 매매 |
| 음식점/카페 | 맛집, 카페, 레스토랑, 베이커리, 꽃집 |
| 미용/뷰티 | 네일, 미용실, 속눈썹, 피부관리 |
| 업체 광고 | 풍선장식, 인형극 섭외, 마술공연, 출강 |
| 등산/관광 | 등산코스, 산행후기, 눈썰매, 키즈카페 |
| 기타 | 강아지유치원, 에버랜드, 콘서트 |

#### 지역 불일치 제외

- **서울(11) 수집 시**: 경기 지역 언급 제외
  - "수원 유치원", "분당 어린이집", "용인시" 등
- **경기(41) 수집 시**: 서울 구 이름 제외
  - "강남구 유치원", "서초 어린이집", "송파구" 등
- **인천(28) 수집 시**: 서울/경기 명시적 언급 제외

## JSON 출력 형식

수집한 후기를 다음 JSON 형식으로 정리해주세요:

```json
{
  "collectedAt": "2026-01-28T10:30:00.000Z",
  "source": "manual_chrome",
  "sidoCode": "11",
  "sidoName": "서울",
  "collector": "Claude in Chrome",
  "reviews": [
    {
      "kindergartenName": "예은유치원",
      "sidoCode": "11",
      "sigunguCode": "11680",
      "title": "예은유치원 1년 다녀본 솔직후기",
      "url": "https://blog.naver.com/example/12345",
      "source": "naver_blog",
      "sourceName": "육아맘일기",
      "snippet": "첫째가 예은유치원에 1년 다녔습니다. 선생님들이 정말 친절하시고...",
      "date": "2025-09-15"
    },
    {
      "kindergartenName": "중앙유치원",
      "sidoCode": "11",
      "sigunguCode": "11650",
      "title": "중앙유치원 재원생 학부모 후기",
      "url": "https://cafe.naver.com/example/67890",
      "source": "naver_cafe",
      "sourceName": "강남맘카페",
      "snippet": "둘째가 중앙유치원 다니고 있는데 방과후 프로그램이 다양해서...",
      "date": "2025-11-20"
    }
  ]
}
```

### 필드 설명

| 필드 | 필수 | 설명 |
|------|------|------|
| `kindergartenName` | O | 유치원 이름 (접미사 포함) |
| `sidoCode` | O | 시도 코드 (11=서울, 41=경기, 28=인천) |
| `sigunguCode` | X | 시군구 코드 (알 수 있는 경우) |
| `title` | O | 글 제목 (HTML 태그 제거) |
| `url` | O | 원본 URL |
| `source` | O | `naver_blog`, `naver_cafe`, `google`, `other` 중 하나 |
| `sourceName` | X | 블로그명 또는 카페명 |
| `snippet` | O | 본문 요약 (100-200자) |
| `date` | X | 작성일 (YYYY-MM-DD 형식) |

## 지역별 수집 가이드

### 서울 (sidoCode: 11)

주요 구 목록:
- 강남구, 서초구, 송파구, 강동구
- 마포구, 용산구, 성동구, 광진구
- 노원구, 도봉구, 강북구, 성북구
- 양천구, 강서구, 영등포구, 구로구

검색어 예시:
```
"[유치원명]" 강남구 후기
"[유치원명]" 서초 재원생
"[유치원명]" 송파 다녀보니
```

### 경기 (sidoCode: 41)

주요 시/군 목록:
- 수원시, 성남시, 용인시, 고양시
- 화성시, 남양주시, 부천시, 안산시
- 평택시, 안양시, 시흥시, 파주시
- 김포시, 광명시, 하남시, 구리시

검색어 예시:
```
"[유치원명]" 분당 후기
"[유치원명]" 수원 재원생
"[유치원명]" 용인 다녀보니
```

### 인천 (sidoCode: 28)

주요 구/군 목록:
- 남동구, 부평구, 계양구, 서구
- 연수구, 미추홀구, 중구, 동구

검색어 예시:
```
"[유치원명]" 인천 부평 후기
"[유치원명]" 남동구 재원생
"[유치원명]" 연수구 다녀보니
```

## 주의사항

1. **저작권**: 수집한 후기는 원본 URL 링크 형태로만 사용합니다.
2. **속도 제한**: 너무 빠른 페이지 탐색은 IP 차단 위험이 있습니다.
3. **로그인 필요 페이지**: 비공개 카페 글은 수집하지 않습니다.
4. **개인정보**: 작성자 실명, 연락처 등 개인정보는 수집하지 않습니다.

---

## 병합 방법

수집한 JSON 파일을 프로젝트에 병합:

```bash
# 병합 스크립트 실행
pnpm merge:chrome-reviews -- --input chrome-reviews-20260128.json --sido 11
```

병합 스크립트가 자동으로:
1. 유치원명으로 `kindercode` 매칭
2. 중복 URL 제거
3. 기존 `public/data/reviews/[sido].json`에 병합
4. 통계 출력
