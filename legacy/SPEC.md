# 🎒 유치원 비교 시트 원클릭 생성기 - 상세 기획서
> **한 줄 요약**: 모바일에서 현재 위치 기반으로 주변 유치원/어린이집을 자동 수집하고, 비교표를 원클릭으로 생성하는 서비스
---
## 1. 프로젝트 개요
### 서비스명 (안)
- **유치원 비교왕**
- **우리동네 유치원**
- **유치원 한눈에**
### 핵심 가치 제안
> **"10분 걸리던 유치원 비교, 30초 만에 끝"**
### 타겟 사용자
| 구분 | 특성 |
|-----|-----|
| **Primary** | 모바일로 웹 접속하는 2-6세 자녀 부모 |
| **Secondary** | 이사 후 새 지역 유치원 탐색 중인 부모 |
| **시즌** | 10-11월 우선모집, 2-3월 일반모집 기간 집중 |
### 핵심 차별점
1. **GPS 기반 자동 위치 감지** - 주소 입력 없이 현재 위치로 검색
2. **모바일 최적화 UX** - 터치 친화적, 빠른 로딩
3. **원클릭 비교표** - 선택만 하면 자동 생성

- **인증 방식**: SNS 로그인 (네이버/카카오/구글)
- **계정 유형**:
  - 개발 계정: 50건 제한 (테스트용)

- **상업적 이용**: 심사 필요 → 초기 비영리로 시작 후 협의

## 4. MVP 기능 상세
### 4.1 위치 기반 검색
#### GPS 위치 감지 (모바일 우선)
```
[앱 접속]
    ↓
[위치 권한 요청] - "주변 유치원을 찾기 위해 위치 정보가 필요합니다"
    ↓
    ├─ [허용] → GPS 좌표 자동 획득 → 지도에 현재 위치 표시
    │
    └─ [거부] → 주소 직접 입력 폼 표시
```
#### 위치 옵션
| 옵션 | 설명 |
|-----|-----|
| 📍 현재 위치 | GPS로 자동 감지 |
| 🏠 집 주소 입력 | 텍스트로 주소 입력 |
| 📌 지도에서 선택 | 핀 드래그로 위치 지정 |
#### 반경 선택
- **1km** - "도보 10분 이내" (기본값)
- **2km** - "자전거/차량 5분"
- **5km** - "통학차량 이용 가능"
### 4.2 검색 결과 화면
#### 목록 뷰 (기본)
```
┌─────────────────────────────────────┐
│ 📍 서울 강남구 역삼동 (변경)          │
│ 반경: [1km ▼]                       │
├─────────────────────────────────────┤
│ 🔍 8개 기관 발견                     │
├─────────────────────────────────────┤
│ ☐ 역삼유치원 (공립)         0.3km   │
│    정원 40명 | 현원 38명 | 🚌 있음   │
├─────────────────────────────────────┤
│ ☐ 해맑은어린이집 (민간)      0.5km   │
│    정원 60명 | 현원 55명 | 🚌 없음   │
├─────────────────────────────────────┤
│ ...                                 │
├─────────────────────────────────────┤
│ [선택한 3개 비교하기 →]              │
└─────────────────────────────────────┘
```
#### 지도 뷰 (토글)
- 카카오맵 기반
- 기관별 마커 표시
- 마커 탭 → 간략 정보 팝업
### 4.3 비교표 생성
#### 비교 항목 (MVP)
| 항목 | 데이터 출처 |
|-----|-----------|
| 기관명 | 일반현황 API |
| 설립유형 | 일반현황 API |
| 주소/거리 | 일반현황 API + 계산 |
| 정원/현원 | 일반현황 API |
| 통학차량 | 통학차량현황 API |
| 급식 | 급식운영현황 API |
| 방과후 과정 | 방과후 과정 API |
| 1인당 면적 | 교실면적현황 API |
#### 비교표 UI (모바일)
```
┌─────────────────────────────────────┐
│ 📊 비교 결과 (3개 기관)              │
├─────────────────────────────────────┤
│        │ 역삼유치원 │ 해맑은 │ 꿈나무 │
├────────┼──────────┼───────┼───────┤
│ 유형   │ 공립     │ 민간  │ 사립   │
│ 거리   │ 0.3km    │ 0.5km │ 0.8km │
│ 정원   │ 40명     │ 60명  │ 80명  │
│ 현원   │ 38명     │ 55명  │ 72명  │
│ 통학🚌 │ ✅       │ ❌    │ ✅     │
│ 급식   │ 직영     │ 위탁  │ 직영   │
│ 방과후 │ ✅       │ ✅    │ ✅     │
│ 면적   │ 3.2㎡    │ 2.8㎡ │ 3.5㎡  │
├─────────────────────────────────────┤
│ [📥 이미지 저장] [📤 카카오 공유]    │
└─────────────────────────────────────┘
```
### 4.4 저장/공유 기능

| 카카오톡 공유 | Kakao SDK 공유 API |
| 링크 복사 | 검색 조건 포함 URL 생성 |

## 8. 개발 일정
