## 1. IA Overview

### 1.1 Information Architecture Principles

| Principle | Application |
|-----------|-------------|
| **Findability** | GPS/주소 기반 즉시 검색, 반경 필터로 범위 조절 |
| **Understandability** | 거리순 정렬, 최적값 강조로 직관적 비교 |
| **Usefulness** | 의사결정에 필요한 핵심 정보만 표시 |
| **Credibility** | 공공 데이터(유치원 알리미) 기반, 출처 명시 |
| **Accessibility** | 모바일 최적화, 터치 친화적 UI |
| **Desirability** | 미니멀 화이트 디자인, 깔끔한 데이터 시각화 |

### 2.3 URL Structure

| Page | URL Pattern | Query Parameters |
|------|-------------|------------------|
| 홈 | `/` | - |
| 검색 결과 | `/search` | `lat`, `lng`, `radius`, `type`, `mode` |
| 비교표 | `/compare` | `ids` (URL 공유 시) |
| 개인정보처리방침 | `/privacy` | - |
| 서비스 소개 | `/about` | - |

#### URL Parameter Specification

```typescript
// /search 파라미터
interface SearchURLParams {
  lat: number;           // 위도 (필수)
  lng: number;           // 경도 (필수)
  radius: 1 | 2 | 5;    // 반경 (기본: 1)
  type: 'all' | 'kindergarten' | 'daycare';  // 기관 유형 (기본: all)
  mode: 'location' | 'address';  // 검색 모드
}

// /compare 파라미터 (공유 URL)
interface CompareURLParams {
  ids: string;  // 콤마 구분 kindercode (예: "K001,K002,K003")
}

// 예시 URL
// /search?lat=37.5012&lng=127.0396&radius=1&type=all&mode=location
// /compare?ids=K001,K002,K003
```

## 3. Navigation System

### 3.1 Navigation Types

| Type | Location | Function |
|------|----------|----------|
| **Global Navigation** | Header | 로고(홈), 서비스 소개 링크 |
| **Local Navigation** | /search Header | 뷰 전환, 필터 |
| **Contextual Navigation** | 컨텐츠 내 | 비교하기 버튼, Load More |
| **Footer Navigation** | Footer | 개인정보처리방침, About |
