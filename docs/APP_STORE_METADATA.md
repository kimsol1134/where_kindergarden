## 앱 개인정보 보호 (App Privacy) - 데이터 수집

위치 기반 검색과 서비스 품질 개선을 위해 다음 항목들을 체크해야 합니다.

### 1. 데이터 수집 여부
- **"이 앱에서 데이터를 수집합니까?"** -> **예 (Yes)**

### 2. 수집하는 데이터 유형
다음 3가지 항목을 선택합니다:

1.  **위치 (Location)**
    - [x] 정확한 위치 (Precise Location)
2.  **사용 데이터 (Usage Data)**
    - [x] 제품 상호 작용 (Product Interaction)
3.  **진단 (Diagnostics)**
    - [x] 충돌 데이터 (Crash Data)
    - [x] 실적 데이터 (Performance Data)

### 3. 세부 설정 답변 (가장 중요)

각 항목별로 "설정"을 누르고 다음과 같이 답변하세요.

#### A. 정확한 위치 (Precise Location)
- **목적**: 앱의 기본 기능 (App Functionality)
- **사용자와 연결됨**: 아니요 (No)
- **추적 목적으로 사용**: 아니요 (No)
> 이유: 주변 유치원 검색에만 사용됨

#### B. 제품 상호 작용 (Product Interaction)
- **목적**: 분석 (Analytics)
- **사용자와 연결됨**: 아니요 (No)
- **추적 목적으로 사용**: 아니요 (No)

#### C. 충돌 데이터 / 실적 데이터 (Diagnostics)
- **목적**: 분석 (Analytics)
- **사용자와 연결됨**: 아니요 (No)
- **추적 목적으로 사용**: 아니요 (No)
