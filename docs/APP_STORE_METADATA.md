## 스크린샷 권장 구성

1. **홈 화면** - 위치 검색 (핵심 기능)
2. **검색 결과** - 목록 + 필터
3. **상세 정보** - 유치원 상세 페이지
4. **비교표** - 3개 유치원 비교
5. **지도 뷰** - 지도에서 유치원 위치 확인

## 체크리스트

App Store Connect 제출 전 확인:

- [ ] 앱 이름 입력
- [ ] 프로모션 텍스트 입력 (170자 이내)
- [ ] 설명 입력 (4,000자 이내)
- [ ] 키워드 입력 (100자 이내)
- [ ] 지원 URL 입력
- [ ] 스크린샷 업로드
- [ ] 연령 등급 설정 완료
- [ ] 심사 연락처 정보 입력 (실제 연락처)
- [ ] 심사원 메모 입력
- [ ] 개인정보처리방침 URL 입력
