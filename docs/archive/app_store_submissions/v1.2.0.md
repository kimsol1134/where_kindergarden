## 주요 변경사항

### 신규 기능
- 15개 시도 지역 학부모 후기 데이터 추가 (세종, 제주 포함)
- 스팸/무관 콘텐츠 정제 및 품질 개선
- 유치원 성격 테스트 페이지 추가
- SEO 최적화 및 UI 개선

### 버그 수정
- 카카오 공유 URL 수정
- 앱스토어 링크 수정

### 메타데이터 수정
- App Store 설명에 학부모 후기 섹션 추가
- box-drawing 문자(━) em dash(—)로 교체
- 프로모션 텍스트 후기 기능 반영
- 심사 연락처 placeholder를 실제 값으로 교체
- 저작권 연도 2025 → 2026 업데이트
- 릴리즈 노트 v1.2.0 작성
