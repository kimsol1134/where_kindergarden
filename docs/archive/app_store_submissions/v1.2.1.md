## 심사원 참고 사항

```
이번 업데이트는 리뷰 데이터 품질 개선 및 카카오 지도 연동 안정성 향상입니다.
앱의 기능 변경은 없으며, 데이터 정제 작업이 주요 변경사항입니다.

테스트 방법은 이전 버전과 동일합니다:
1. 앱 실행 시 위치 권한을 허용해 주세요.
2. 홈 화면에서 "현재 위치로 검색" 버튼을 탭하면 주변 유치원 목록이 표시됩니다.
3. 검색 결과에서 유치원을 선택하면 상세 정보와 학부모 후기를 볼 수 있습니다.

테스트 위치 추천: 서울 강남구 (유치원 밀집 지역)
```
