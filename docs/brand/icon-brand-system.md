# Icon Brand System

## Core Read
- The product brand is anchored to the existing app icon, not the legacy mascot logo.
- The icon combines four ideas at once: a safe white stage, a green kindergarten-bag silhouette, a yellow morning sun, and a magnifying glass for discovery.
- Visual tone should feel calm, bright, tactile, and trustworthy rather than playful-cartoonish.

## Visual Tokens
- `Mist White`: primary page background and frosted surfaces.
- `Leaf Green`: primary action, map emphasis, active state, compare highlight.
- `Sun Yellow`: optimism, discovery cues, badges, warm accents.
- `Warm Sand`: secondary neutral for search chrome, icon handle, dividers.
- Large rounded corners, blurred translucent cards, soft ambient shadows, and layered overlapping shapes are part of the brand language.

## Usage Rules
- Use the app icon as the default mark in headers, footers, splash, manifest, and structured data.
- Reserve the legacy `logo.png` house-heart illustration for optional editorial use only.
- Search surfaces should look like frosted tools placed on a calm canvas, not generic flat admin panels.
- Comparison states should emphasize clarity first: warm neutrals for scaffolding, leaf green only for intentional highlights.
- Motion should be slow and buoyant. Prefer fades, drift, and soft scale shifts over sharp snaps.

## Web Scope In Phase 1
- Rebrand landing, search header chrome, compare header chrome, manifest, and shared shell surfaces.
- Keep information architecture and route structure intact.
- Do not introduce a second brand palette for campaigns or App Store materials.
