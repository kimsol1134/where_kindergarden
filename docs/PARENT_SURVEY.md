## 노출 정책

네이티브 iOS 검색에서 서로 다른 유치원 상세 화면을 두 곳 실제로 본 뒤, 상세를 닫고 검색 목록으로 돌아온 시점에 안내 카드를 표시한다. 행 선택만으로는 횟수를 늘리지 않는다. 비교 탭으로 이동하면 표시하지 않는다. 첫 실행 직후에는 표시하지 않지만, 첫 실행 중이라도 두 곳을 살펴본 뒤에는 참여할 수 있다.

설문 카드가 나타나면 목록 패널을 중간 높이로 열고 카드 위치로 스크롤한다. 스크롤 콘텐츠 안에 두어 큰 글씨에서도 내용을 읽을 수 있다. 첫 노출 이력은 UserDefaults에 저장해 같은 캠페인은 앱 재실행 이후에도 자동으로 다시 권하지 않는다. 닫기·링크 열기 성공 시 카드를 숨긴다. URL 열기 실패는 안내와 재시도를 제공한다. 기기 로컬 제한이므로 앱 삭제·재설치나 다른 기기에서는 다시 표시될 수 있다.

설문과 StoreKit 리뷰 요청은 `SessionPromptGate`를 공유한다. 먼저 표시를 예약한 쪽이 해당 앱 실행 동안 다른 자동 요청을 막는다. 백그라운드 복귀로 초기화하지 않는 보수적 제한이며 Mixpanel의 30분 세션과 동일한 정의는 아니다. 사용자가 직접 누르는 더보기의 앱스토어 리뷰 링크는 별개다.

## 질문

1. 지금 유치원을 알아보는 상황은 무엇인가요? (필수, 단일 선택)
   - 다음 학년도 입학 / 지금 입학·전원 / 미리 알아보는 중 / 기타
2. 오늘 앱을 이용하고도 확인하지 못한 정보가 있나요? 없으면 ‘없음’이라고 적어주세요. (필수, 자유응답)
3. 가장 최근에 유치원 정보를 찾다가 막혔을 때, 어떻게 해결했나요? 아직 해결하지 못했거나 막힌 적이 없다면 그대로 적어주세요. (필수, 자유응답)
4. 이 경험에 관해 10분 정도 더 이야기해 주실 수 있나요? (선택)
   - 이메일 수집·이용에 동의하고 참여 / 설문만 제출
   - 선택하지 않거나 거절하면 연락처 화면을 건너뛰어 제출한다.
   - 동의한 경우에만 선택 이메일 입력 섹션으로 이동한다. 이메일도 필수는 아니다.

폼에서 기본 설문 답변에 개인정보를 적지 않도록 안내한다. 후속 대화의 이메일 수집 목적, 보유 기간, 동의 거부 가능성을 선택 항목에 표시한다. 설문·연락처를 Mixpanel에 전송하거나 기존 IDFV와 연결하지 않는다. 응답자 식별자나 검색어를 설문 URL에 붙이지 않는다.

**운영자 할 일:** 동의 이메일은 일정 조율·서비스 개선 대화에만 사용하고 안내한 대로 제출일로부터 30일 이내 삭제한다. Google Forms에 자동 만료 기능을 구현한 것은 아니므로 응답 원본과 별도 내보내기 파일의 연락처를 운영자가 관리해야 한다. 이번 작업에서는 실제 사용자에게 연락하지 않았다.

## 계측과 분석

| 이벤트 | 의미 |
|---|---|
| Survey Invitation Shown | 카드 onAppear, 해당 캠페인 최초 1회 |
| Survey Invitation Dismissed | 닫기 선택 |
| Survey Link Tapped | 참여 버튼 탭. 재시도는 별도 클릭 |
| Survey Link Open Result | OS의 URL 열기 접수 결과. `accepted` Bool |

공통 속성: `survey_id`, `source=search_after_detail`, `detail_count`. 기존 앱 버전·세션 등 super properties는 그대로 사용한다. 클릭 및 OS 인계 성공은 설문 열람·제출 완료가 아니다. 실제 제출 수는 Google Forms 응답 탭에서 센다. 외부에 설문 링크를 공유하면 앱 노출과 연결되지 않은 응답이 포함될 수 있으므로 앱 퍼널의 완전한 전환율로 해석하지 않는다. 실제 제출 이벤트를 앱에 추정 생성하지 않는다.

## 운영 변경

`Services/ParentSurvey.swift`의 `ParentSurveyCampaign.current`에서 캠페인 ID와 공개 응답 URL을 관리한다. URL이 없거나 편집 링크·다른 호스트·HTTP·추적 쿼리가 들어가면 초대가 비활성화된다. 새 캠페인 ID로 바꾸면 다시 노출될 수 있으므로 단순 문구 수정만으로 ID를 바꾸지 않는다. 공개 폼이 닫혔다면 앱 업데이트에서 URL을 nil로 설정한다. 원격 종료 스위치는 이번 최소 범위에 포함하지 않았다.
