# 맘카페 후기 수동 수집 가이드 (인천 지역)

이 가이드는 자동 수집으로 확보하기 어려운 인천 지역 맘카페의 유치원 후기를 직접 수집하여 앱에 통합하는 방법을 안내합니다.

## 1. 준비물

수집을 시작하기 전에 다음 파일들이 준비되었는지 확인하세요.

1.  **수집 대상 목록**: `public/data/manual_collection_targets_incheon.csv`
    *   인천 지역 유치원의 이름, ID, 주소가 포함되어 있습니다.
    *   엑셀이나 텍스트 에디터로 열어두세요.
2.  **데이터 입력 템플릿**: `scripts/data-output/reviews-raw-manual-28.template.json`
    *   수집한 데이터를 입력할 JSON 양식입니다.

## 2. 수집 파일 생성

1.  `scripts/data-output/reviews-raw-manual-28.template.json` 파일을 복사하여 **`reviews-raw-manual-28.json`** 파일을 만드세요.
2.  이 파일에 수집한 데이터를 계속 추가하게 됩니다.

> **주의**: 파일명은 반드시 `reviews-raw-`로 시작하고 확장자가 `.json`이어야 나중에 시스템이 자동으로 인식할 수 있습니다.

## 3. 수집 절차 (Step-by-Step)

### 단계 1: 유치원 검색
1.  **대상 목록(CSV)**에서 유치원 이름을 하나 고릅니다. (예: "무지개유치원")
2.  **맘카페(네이버 카페 등)**에 접속하여 해당 유치원 이름을 검색합니다.
    *   팁: "무지개유치원 후기", "무지개유치원 설명회", "무지개유치원 장단점" 등으로 검색하면 좋습니다.

### 단계 2: 유효한 후기 선정
다음 조건에 맞는 글을 찾습니다.
*   **광고가 아닌 실제 학부모의 후기**
*   최근 3년 이내의 글 (권장)
*   내용이 너무 짧지 않고 정보가 있는 글

### 단계 3: 데이터 입력 (JSON 작성)
`reviews-raw-manual-28.json` 파일을 열고 아래 서식에 맞춰 데이터를 입력합니다. 여러 개를 입력할 때는 쉼표(`,`)로 구분하여 객체(`{}`)를 추가하세요.

**입력 예시:**
```json
[
  {
    "kindergartenId": "CSV 파일에 있는 ID 복사 (예: 1ecec08d-0a2e...)",
    "kindergartenName": "유치원 이름 (예: 무지개유치원)",
    "title": "게시글 제목 (예: 무지개유치원 보내보신 분 계신가요?)",
    "url": "게시글 링크 (예: https://cafe.naver.com/...)",
    "source": "naver_cafe",
    "sourceName": "카페 이름 (예: 인천맘 소중한인연)",
    "snippet": "게시글의 핵심 내용 요약. 2-3줄 정도로 내용을 복사해서 붙여넣으세요.",
    "date": "작성일 (YYYY-MM-DD 형식, 예: 2024-03-15)",
    "collectedAt": "2024-03-20T10:00:00.000Z", 
    "relevanceScore": 5
  }
]
```

*   `kindergartenId`: **가장 중요합니다.** CSV 파일에서 해당 유치원의 ID를 정확히 찾아 넣으세요.
*   `kindergartenName`: 유치원 이름을 입력합니다.
*   `title`: 게시글 제목을 입력합니다.
*   `url`: 게시글의 링크(URL)를 입력합니다.
*   `snippet`: 내용의 일부를 복사하여 넣습니다. (검색 결과에 보여질 내용이므로 중요한 문장을 넣으면 좋습니다)
*   `date`: 글 작성 날짜를 `YYYY-MM-DD` 형식으로 입력합니다.
*   `collectedAt`: 현재 시간을 적당히 넣거나, 위 예시를 그대로 둬도 됩니다.
*   `relevanceScore`: 직접 확인한 유용한 글이라면 **5**를 입력하세요. (자동 필터링이나 정렬에서 우선순위를 갖게 됩니다)

## 4. 데이터 반영 (앱에 통합)

수집이 완료되면 다음 명령어를 터미널에서 실행하여 앱 데이터(`public/data/reviews/28.json`)에 반영합니다.

```bash
pnpm curate:reviews
```

이 명령어는 `scripts/data-output/` 폴더에 있는 모든 `reviews-raw-*.json` 파일(수동 수집 파일 포함)을 읽어와서 하나로 합칩니다.
특히 `relevanceScore`가 높고 최신 날짜인 항목들을 우선적으로 처리합니다.

## 5. 확인

```bash
# 통합된 파일 확인 (VS Code 등 에디터에서 확인)
code public/data/reviews/28.json
```

파일 내에서 방금 추가한 후기(제목이나 ID로 검색)가 잘 포함되었는지 확인하세요.

---

### Tip: 엑셀이나 구글 스프레드시트로 작업하고 싶다면?
JSON 포맷을 직접 맞추기 어렵다면:
1. 엑셀에 `ID`, `이름`, `제목`, `URL`, `카페명`, `요약`, `날짜` 컬럼을 만들어 정리합니다.
2. ChatGPT나 Claude에게 "이 엑셀 내용을 JSON 포맷(reviews-raw format)으로 바꿔줘"라고 요청하여 변환 결과를 파일에 붙여넣으세요.
