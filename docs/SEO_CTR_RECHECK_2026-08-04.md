## 비판적 원인 분석

1. **클릭 증가는 있었지만 CTR 개선은 아니었다.** 홈 클릭이 5→16으로 늘어난 점은 수정 title/H1이 완전히 실패한 것은 아니라는 신호다. 그러나 홈 노출이 737→3,017로 더 빠르게 늘어 CTR은 0.5%로 낮아졌다.
2. **노출 절반 이상이 서비스 의도와 맞지 않는다.** `유치원 알리미`는 공식 사이트 탐색 의도가 강하다. 이 문구를 다시 홈 title에 전면 배치하면 클릭을 조금 얻을 수 있어도 공식 서비스로 오인시키고 이탈을 늘릴 수 있으므로 채택하지 않았다. 대신 PWA 이름과 키워드에서 공식 서비스명처럼 보이는 표현을 줄였다.
3. **브랜드 검색에는 현재 스니펫이 잘 작동한다.** `우리동네 유치원` CTR 38.5%, 붙여 쓴 변형 16.7%는 브랜드·서비스명 일치 시 클릭 가능성이 충분함을 보여준다. 홈 title을 다시 즉시 바꾸면 7월 12일 실험과 다음 측정 창을 또 섞게 되므로 유지했다.
4. **`/search`는 발견·색인 단계에서 막혔다.** 네이버 TOP30과 GSC 모두 행이 없고 Google은 사이트에서 두 URL만 알고 있었다. 검색 페이지의 정적 H1 누락과 sitemap 미제출이 이 문제를 악화했다.
5. **가장 명확한 기술 오류는 진단 수치와 일치한다.** 28개 중복 description은 페이지네이션 코드 한 곳, 31개 리디렉션은 slash 없는 sitemap·canonical·내부 링크, 접근 불가 5개는 사라진 가이드 파일로 각각 원인이 재현됐다.
6. **성과가 있던 콘텐츠를 404로 만든 배포 회귀가 있었다.** `/guides/`는 2클릭/9노출/22.2%였는데 현재 404였다. CTR이 좋은 소규모 랜딩 페이지를 잃은 것이며, 홈 title만 다듬는 것보다 우선 복구할 가치가 높다.

## 적용한 코드 변경

- 루트 레이아웃의 홈 canonical 상속을 제거하고 홈에만 `/` canonical 지정
- `/search/`, `/compare/` 정적 HTML에 고유 H1 추가
- `/reviews/`에 self-canonical과 고유 title/description/OG/Twitter 추가
- 후기 페이지네이션 2~64의 description을 페이지 번호별로 고유화
- 중복 별칭 `/reviews/all/page/1/` 정적 생성을 제거하고 실제 1페이지 URL을 `/reviews/all/`로 단일화
- 모든 canonical, OG URL, sitemap, 주요 내부 링크를 실제 200 응답인 trailing-slash URL로 통일
- `noindex`인 `/test/`를 sitemap에서 제거하고 고유 메타데이터 지정
- `/about/`에 고유 title/description/canonical/OG/Twitter 추가
- `/splash-preview/*` 전체를 `noindex,nofollow`로 지정
- 과거 운영에서 사라진 `/guides/`와 가이드 글 5개를 200 정적 페이지로 복구
- 가이드 6개 URL을 홈 내비게이션·푸터·sitemap에 다시 연결
- PWA 이름을 `우리동네 유치원 - 내 주변 유치원 찾기`로 명확히 하고 홈 meta keywords에서 `유치원 알리미`를 제거

현재 홈 title은 바꾸지 않았다. 클릭 절대량은 증가했고 브랜드 검색 CTR도 좋기 때문에, 진단 오류와 발견 문제를 먼저 제거한 뒤 깨끗한 2~4주 창으로 다시 판단하는 것이 인과관계 측정에 유리하다.

## 배포 후 해야 할 일

1. 이 변경을 검토하고 프로덕션에 배포한다.
2. 배포 HTML에서 `/guides/` 6개가 200인지, 후기 페이지 description이 고유한지 다시 확인한다.
3. Google Search Console과 네이버 서치어드바이저에 `https://where-kindergarden.vercel.app/sitemap.xml`을 제출한다.
4. 홈, `/search/`, `/reviews/`, `/guides/`의 재수집을 요청한다.
5. 최소 14일, 권장 28일 뒤 같은 항목을 다시 수집한다.
6. 다음 측정에서는 전체 CTR과 함께 `유치원 알리미` 두 변형을 제외한 핵심 탐색 쿼리 CTR을 별도로 본다. 전체 CTR만 보면 공식 서비스 탐색 노출이 제품 개선 효과를 계속 가린다.

외부 콘솔의 sitemap 제출과 재수집 요청은 계정 상태를 변경하는 작업이므로 이번 재점검에서는 수행하지 않았다.
