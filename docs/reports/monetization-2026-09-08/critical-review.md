# 수익화 제안 비판적 재검토

2026-09-08. 같은 날 확인한 Mixpanel 실측치와 공식 서비스 기능을 바탕으로 최초 제안을 재평가했다. 신규 사용자 인터뷰·가격 노출·결제 실험은 수행하지 않았다.

## 수정 결론

9,900원 입학 준비 패스를 개발 우선순위 1위로 추천한 판단을 철회한다. 현재 관측 데이터는 탐색 기능 사용을 입증하지만 상담 정리·가족 협업·질문 생성에 대한 미충족 수요나 지불 의향을 입증하지 않는다. 아무도 사지 않는다고 확정할 수는 없지만, 현 구성으로 개발비를 회수할 만큼 팔린다고 기대할 근거가 부족하다. 당장은 유료 기능 개발을 보류한다.

## 최초 추론의 문제

- 구독 근거가 약하다는 사실에서 일회성 상품이 유망하다는 결론은 나오지 않는다. 두 모델 모두 수요가 없을 수 있다.
- 후보 2곳 도달자 138명은 비교 기능 사용자다. 제안 상품을 필요로 하거나 가격을 본 138명이 아니다.
- 결원 101명은 섹션 노출 사용자다. 능동적 조회·반복 확인·알림 신청과 같지 않다.
- 낮은 D7은 과업 완결, 서비스 불만, 다른 채널에서의 후속 행동을 구분하지 못한다. 상담·선택 완료 결과가 미계측이다.
- 3~10% 구매율만 제시하면 가정이라고 밝혀도 낙관적인 기준점을 만든다. 0건 시나리오를 포함하고 개발·지원 비용을 반영했어야 한다.
- 50명 중 구매 3건은 임의의 운영 기준이다. 유료 수요의 초기 신호는 될 수 있지만 충분한 사업성 검증은 아니다.

## 구매자가 거절할 이유

| 제안 가치 | 반론 | 필요한 증거 |
|---|---|---|
| 상담 질문 제공 | 실제로 궁금한 것은 해당 원의 최신 답변이며 일반 질문 목록이 아닐 수 있다 | 기존 질문 자료로 해결 못한 최근 구체 사례 |
| 상담 메모·답변 비교 | 메모 앱·사진·메신저로 처리 가능한 과업에 추가 입력이 생김 | 기존 방식의 반복 실패와 충분한 시간 절감 |
| 가족 의사결정 기록 | 가족 공유 결과 이벤트가 주간 4명뿐이며 협업 수요는 미확인 | 실제 가족 협의에서 발생한 문제와 사용 빈도 |
| 일정 알림 | 직접 입력해야 하면 기존 캘린더 대비 차별성이 약함 | 원별 일정 자동 확보·변경 확인이 가능한지 |
| AI 정리 | 원천 정보가 같다면 중요한 불확실성을 해소하지 못할 수 있음 | 독점적·검증된 정보 또는 검증 가능한 업무 대행 가치 |

공식 통합정보 서비스에 검색·비교 기능이 있고, 공식 유치원입학 서비스는 정보 검색·신청·선발 결과를 제공한다. 우리 앱의 편의성은 무료 사용을 유도할 수 있어도 결제 이유와 동일하지 않다.

## 대안도 같은 기준으로 평가

- 결원 알림: 실시간성, 실제 변경 빈도, 사용자에게 행동 기회가 있는지가 모두 필요하다. 차년도 정기 모집 수요와 당해연도 중도 입학 수요를 섞지 않는다. 공식 입학 서비스는 선착순이 아니라고 안내하므로 빠른 알림이 정기 모집 당첨 가능성을 높인다고 판매하면 안 된다. 현재 관측 버전은 8/20으로 갱신 검증도 부족하다.
- 기관 광고·상담 유입: 비용 지불자를 기관으로 바꿔도 유효한 상담 성과가 필요하다. 조회 기관 539곳 중 538곳의 주간 조회자가 5명 미만이다. 지역을 좁혀 유효 문의를 실제로 만들기 전에는 기관의 광고비 지불을 낙관할 수 없다.
- 기관 관리 SaaS: 일정·예약 관리 문제에 대한 원장 인터뷰나 기존 도구 대체 의향이 없다. 현 앱 수익화의 작은 확장이 아니라 별도 제품·영업·지원 부담이 될 수 있다.
- 제휴 판매: 학부모가 탐색 다음 단계에서 실제로 구매하는 품목과 추적 가능한 주문이 필요하다. 현재 로그에는 구매 의도가 없다.
- 배너 광고: 결제 저항은 낮지만 실제 노출 수·광고 단가·채움률이 없어 매출을 산출할 수 없다. 현재 광고 없음 약속을 바꾸는 비용도 있다. 가상의 MAU×노출×eCPM으로 확정 전망을 만들지 않는다.
- 원시 데이터·기관별 인사이트 판매: 지역 표본과 차별적 정보, 적절한 활용 범위가 부족하다.

## 규모와 비용

138명 전원에게 9,900원을 노출한다는 가정에서 구매율 0%는 0원, 1%는 기대 총매출 13,662원, 5%는 68,310원이다. 기대 구매 수는 실제 정수 주문 수와 다르다. 전원 노출도 보장되지 않는다.

예를 들어 개발·운영 투입을 임의로 100만 원으로 잡더라도 수수료 등을 무시한 최소 회수 주문은 ceil(1000000/9900)=102건이다. 이는 해당 138명의 약 74%에 해당한다. 미래 유입과 더 긴 시즌 전체 매출은 별도이며, 이 계산은 현재 한 달 규모에서 투입 대비 매출이 작다는 점만 보여준다. 순이익 손익분기점은 주문당 수수료·세금·환불·지원 원가를 차감해 다시 계산해야 한다.

## 다음 행동

이번 시즌은 유료 기능 제작보다 미해결 과업 확인에 제한된 시간을 쓴다. 최근 비교 사용자 5~10명에게 마지막으로 유치원을 고를 때 못 알아낸 정보, 앱을 나온 뒤 한 행동, 결국 해결한 방법, 실제 쓴 시간·비용을 묻는다. ‘이 기능이 있으면 살까요’ 같은 호의적 가상 답변을 수요 증거로 삼지 않는다. 인터뷰 모집은 사용자 동의가 있는 인앱 모집 등으로 설계하며 자동으로 연락하지 않는다.

인터뷰에서 같은 미해결 문제가 반복되고, 공개 정보·메모·전화로 충분히 해결되지 않으며, 제공 가능한 결과와 비용이 맞을 때만 샘플을 만든다. 희망자가 없으면 유료화를 미루는 것이 정상적인 종료다. 최신성·후기 연결 품질·탐색 성공을 개선해 무료 서비스 가치를 높이는 선택도 유효하다. 데이터는 당장 판매할 자산보다는 무엇을 개선하고 어떤 수요를 검증할지 정하는 근거로 사용하는 편이 합리적이다.
